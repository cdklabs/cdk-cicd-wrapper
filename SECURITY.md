# Reporting Security Issues

We take all security reports seriously. If you discover a potential security issue
in this project, we ask that you notify AWS/Amazon Security via our
[vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/)
or directly via email to [aws-security@amazon.com](mailto:aws-security@amazon.com).

Please do **not** create a public GitHub issue for security reports.

See the [AWS Vulnerability Reporting](https://aws.amazon.com/security/vulnerability-reporting/)
page for more information.
